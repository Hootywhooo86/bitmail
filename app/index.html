CONNECT YOUR GMAIL

bitmail talks straight to Google from your browser. Your mail never goes to a 128bit server. To sign in, it needs a Google OAuth Client ID, a one-time setup:

  1. Open console.cloud.google.com and create a project.
  2. Enable the Gmail API (APIs & Services → Library).
  3. Set up the OAuth consent screen (External; add yourself as a test user).
  4. Credentials → Create credentials → OAuth client ID → Web application.
  5. Add this page's origin to Authorized JavaScript origins:
  6. Paste the Client ID below.
